Getting Started

Open IntelliGlossary from Confluence Apps. The main navigation contains Terms, Discovery, Import / Export, Settings, and Audit. Some tabs appear only to administrators.

  1. Choose a scope. Use Company for terminology shared everywhere, or select a Confluence space for local terminology.
  2. Add or submit a term. Administrators save terms directly. Other licensed Confluence users submit terms for review.
  3. Approve the definition. A reviewer or Glossary Admin approves the submission before it becomes part of the published glossary.
  4. Use it while reading. Open the IntelliGlossary byline on a published page to view matching terms and definitions.
Scope precedence: when a space glossary contains the same term as the company glossary, the space-specific definition takes precedence in that space.

Glossary Admins

Confluence site administrators, configured Glossary Admins, and space administrators within their own spaces can manage glossary content. Only administrators can configure roles and providers.

Reviewers

Reviewers see all submitted terms and can approve them or request changes. To preserve four-eyes review, reviewers cannot approve their own submissions.

Normal Users

Licensed Confluence users who are not guests or external collaborators can submit new terms. Their submissions enter Review status and are visible to them while awaiting a decision.

Terms

The Terms table is the authoritative list of glossary content. Search definitions and categories, then filter by Scope or Status. Select a column heading to sort it.

Add or Submit a Term

Select Add Term as an administrator or Submit Term as a contributor. The only essential fields are:

  • Term: the word or phrase people encounter.
  • Definition: the approved organizational meaning.

Optional details include aliases, categories, owner team, reference URL, acronym behavior, translations, and lifecycle status. Previously used categories appear as autocomplete choices.

Lifecycle statuses

  • Draft: incomplete or returned for changes.
  • Review: submitted and waiting for a reviewer.
  • Approved: available to readers and page matching.
  • Deprecated: retained for governance but no longer active.

Review Workflow

User submits→Review→Approve→Approved

Reviewers locate items with Review status in the Terms table. Use the green check to approve or the request-changes action to return the term to Draft. Reviewers cannot delete terms, change settings, or review their own submissions.

Good review practice: confirm that the definition is concise, organization-specific, understandable without page context, and does not duplicate an existing term or alias.

Discovery

Discovery scans eligible published Confluence content for candidate terminology. It helps administrators find project names, acronyms, CamelCase words, and repeated phrases that may need governed definitions.

  • Accept: create a glossary term from the candidate.
  • Edit: adjust the candidate and definition before accepting it.
  • Ignore: suppress a term from future discovery results.
  • Dismiss: remove a candidate that is not useful.
  • Restore: return a recently ignored or dismissed candidate to Pending.

Ignored and dismissed items remain reversible in the table for one day and can be exported from Import / Export. Existing glossary terms are automatically discarded from Discovery.

AI Suggest Definitions

Administrators can generate missing candidate definitions as a background job. Existing definitions are skipped. Progress is persisted, provider rate limits are retried, and usage is recorded in Audit.

Reading Confluence Pages

On a published Confluence page, open the IntelliGlossary byline panel to see approved terms found on that page. The term list shows definitions and occurrence counts. Select View Matches to open matching excerpts; hover a highlighted term to see its definition.

Matching respects full word boundaries, multi-word phrases, aliases, synonyms, configured translations, and optional plural matching. Acronyms can be restricted to uppercase to reduce false positives. Code, links, embedded cards, and unsupported page elements are excluded from scanning.

Import and Export

Glossary Admins can transfer three datasets: Terms, Discovered Terms, and Ignored Terms. Choose the dataset before importing or downloading.

  • CSV: best for simple editing and system interoperability.
  • Excel: preserves structured columns in a familiar workbook.
  • JSON: best for backups and technical migrations.

Imports merge supported data while skipping duplicates. Export before a large import so you have a portable snapshot.

AI Definition Assistant

AI is disabled by default. A Glossary Admin enables it under Settings → AI Definition Assistant and selects one of these modes:

  • Built-in trial provider.
  • Google Gemini or Groq with an organization-owned key.
  • OpenAI or Anthropic.
  • A private OpenAI-compatible HTTPS endpoint, with an optional token.

Content is sent only when a user requests a definition or starts the Discovery batch action. AI output is a draft and should always be reviewed. Provider keys are stored using Forge secret storage and are not displayed again after saving.

Settings and Audit

Settings

Glossary Admins configure approval behavior, language, user roles, and the AI provider. Search Atlassian users by visible name when adding Glossary Admins or Reviewers.

Audit

The Audit tab records governance events such as submissions, approvals, requested changes, deletions, Discovery actions, imports, settings changes, and batch AI requests. Administrators can prepare an Audit CSV for review or evidence collection.

Troubleshooting

I cannot see an administration tab

Import / Export, Settings, Audit, and Discovery management require Glossary Admin or applicable space-admin access.

I cannot approve a term

Confirm that you are configured as a Reviewer, that the term is in Review status, and that another user submitted it. Reviewers cannot approve their own submissions.

AI says it is disabled

Ask a Glossary Admin to open Settings, enable the AI Definition Assistant, choose a provider, and save. Provider errors are shown in the app instead of as generic Atlassian invocation failures.

A term is not detected on a page

Confirm that the term is Approved, the page is published, the correct scope applies, and acronym case or spelling matches the term settings.

The app asks for access

Grant IntelliGlossary access to Atlassian apps when prompted. For a production installation shared by link, the site administrator must install the production app and users may need to authorize requested scopes.
