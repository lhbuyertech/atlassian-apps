Getting Started

IntelliDiagram adds one macro to the Confluence page editor. There is nothing to configure after installation.

  1. Edit a page. Open any Confluence page in edit mode, or create a new one.
  2. Insert the macro. Type / and choose IntelliDiagram. The editor opens straight away.
  3. Write or paste your source. The live preview updates as you type. Pick a starter template if you want something to edit.
  4. Save, then publish the page. The diagram renders in place for everyone who can view the page.
Looking for the app after install? Open Apps → IntelliDiagram for a one-minute interactive guide, a template gallery, and a button that creates a practice page for you. The macro itself lives in the page editor.

The Editor

The editor has the source on the left and a live preview on the right.

ControlWhat it does
TitleOptional heading shown above the diagram. Titles are added to Confluence search.
DialectAuto-detect, Mermaid, Graphviz, or Markdown. Auto-detect tells you what it recognized and why; choose a dialect yourself to override it.
Starter templateInserts a working example. Your existing source is kept above it as comments, and Ctrl/Cmd+Z undoes the insertion.
SourcePlain text. Tab inserts two spaces. The counter shows lines, characters, and how much of the storage limit is used.
SaveStores the source in the page. Nothing is saved until you choose Save.
Convert to SVG / PNGAppears once a Mermaid or Graphviz preview is ready. See Convert to an Image.

Changing a diagram later

Edit the page, then double-click the diagram, or select the macro and choose Edit. Diagram source is part of the page, so it can only be changed while the page is in edit mode.

Supported Syntax

Mermaid

Flowchart, sequence, class, state, entity relationship, Gantt, pie, mindmap, timeline, user journey, git graph, quadrant, requirement, C4, sankey, XY chart, block, packet, architecture, kanban, radar, and treemap diagrams. Each has a starter template in the editor. See the Mermaid documentation for syntax.

flowchart TD
  A[Start] --> B{Approved?}
  B -->|Yes| C[Publish]
  B -->|No| D[Revise]
  D --> B

Labels are plain text. HTML inside labels and click actions that run scripts are not supported, by design.

Graphviz

Graphs written in the DOT language, laid out with the dot engine.

digraph G {
  rankdir=LR
  Draft -> Review -> Published
}

Markdown

Headings, emphasis, lists, links, tables, block quotes, inline code, and fenced code blocks. Raw HTML in Markdown is shown as text, not rendered, and images hosted on other sites are not loaded.

PlantUML is not supported in this version. PlantUML has no in-browser renderer, and IntelliDiagram does not send your source to an external server.

Viewing a Diagram

Diagrams are drawn as SVG, so they stay sharp at any zoom level, and they follow Confluence's light or dark theme. Each diagram appears at its natural size, scaled down when it is wider than the page. The controls below it are:

  • −  %  + — zoom out and in, in 5% steps. Select the percentage to return to that starting size. Zoom is a personal view setting and resets when the page reloads.
  • Download Image — saves the diagram as a standalone SVG file.
  • Copy Image — copies the diagram to the clipboard as an SVG image, where your browser supports it.
  • Copy Source — copies the text behind the diagram.

If the source cannot be rendered, the macro shows the renderer's message, the line it stopped at, and your source, so nothing is lost.

Convert to an Image

A diagram macro is rendered live each time the page loads. When you want an ordinary Confluence image instead, for example to resize it with Confluence's image handles or to have a picture in a PDF export, open the editor and choose Convert to SVG or Convert to PNG.

  • The image is uploaded as an attachment to the page and inserted directly below the diagram.
  • The diagram macro stays where it is, with its source intact. Delete the macro yourself if you only want the image.
  • The image is a snapshot. It does not update when you change the source; convert again if you need a new one.
  • You need permission to edit the page. If someone else saved the page while you were converting, IntelliDiagram stops rather than overwrite their change; reload and try again.

Search and Export

Confluence search

The diagram title and source are added to the Confluence search index, so searching for a word that appears in a diagram finds the page.

PDF and Word export

  • Markdown is exported as formatted content: headings, lists, tables, and code blocks.
  • Mermaid and Graphviz are exported as their source in a code block, with the title above it. To include the picture in an export, convert the diagram to an image first.

Page history and copies

The source is stored in the page, so it is versioned with page history, restored with page versions, and carried along when a page is copied or used as a template.

App Home

Apps → IntelliDiagram is a place to learn and experiment. Nothing you do there changes a real page unless you ask it to.

  • Start here — a short interactive walkthrough with an editable example and live preview.
  • Create a practice page — choose a space and IntelliDiagram creates a real page containing three working diagrams for you to edit or delete. The page is created in your name, in a space you already have permission to add pages to.
  • Template gallery — ready-to-paste starters with a Copy button.

Permissions and Privacy

IntelliDiagram asks for four Confluence permissions, and uses each only when you do something that needs it, always as you and with your own access.

PermissionUsed for
View pagesReading the page when you convert a diagram to an image, to find where the image goes.
View spacesListing your spaces when you create a practice page.
Write pagesCreating a practice page, and placing a converted image on a page.
Upload attachmentsAttaching a converted SVG or PNG to the page.
Your data stays in Atlassian. IntelliDiagram has no database and no permission to contact any outside service. Diagram source is stored in your pages; diagrams are rendered in your browser. See the Privacy Policy and Security Policy.

Licensing

IntelliDiagram is licensed through the Atlassian Marketplace, which manages trials, subscriptions, and billing. If a trial or subscription ends, diagrams already on your pages keep rendering and their source stays in your pages. Saving changes to a diagram, converting to an image, and creating a practice page need an active license; the editor tells you when that is the case.

Limits

  • 28,800 characters of source per macro. The editor shows how much is used and will not save beyond the limit rather than cut your source short. Split a long document across macros.
  • Converted images are limited to 4 MB.
  • Zoom is not saved with the page.
  • Page width is a Confluence page setting. A wide diagram is scaled down to the width Confluence gives the macro; set the page to wide or full width for more room, or zoom in.

Troubleshooting

The macro shows the word “extension” or an empty space

The macro is still loading. A page with many diagrams can take several seconds to draw them all.

“Diagram could not be rendered”

The message names the line the renderer stopped at. Check the syntax, or choose the dialect yourself instead of Auto-detect. Starter templates are a quick way to compare against a working example.

Save says the page must be in edit mode

Edit the page first, then double-click the diagram.

Convert to SVG or PNG fails

Check that you can edit the page. If the message says the page was edited by someone else, reload the page and convert again.

An image in Markdown does not appear

Images hosted on other sites are not loaded. Add the image to the page with Confluence instead.

I cannot find the macro

It is in the page editor, not in the Apps menu: edit a page, type /, and choose IntelliDiagram.
