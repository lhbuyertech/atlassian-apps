Contact support
Open a request in the Support Center or email support@lhbuyertech.us.
Include your Confluence site URL, the page where the problem appears, and the diagram source if you can share it.

Before you contact us

  • The macro shows “extension” or an empty space. It is still loading. A page with many diagrams can take several seconds; wait before concluding it is broken.
  • “Diagram could not be rendered.” The message names the line the renderer stopped at and shows your source. Check the syntax against the Mermaid or Graphviz DOT documentation, or pick the dialect yourself instead of Auto-detect.
  • Save says the page must be in edit mode. Edit the page first, then double-click the diagram. Diagram source is part of the page, so it can only be changed while the page is being edited.
  • Convert to SVG / PNG fails. You need permission to edit the page and add attachments. If someone else saved the page meanwhile, reload and try again.
  • A long document will not save. Source is limited to 28,800 characters per macro. Split it across two macros.
  • An image in Markdown does not appear. Images hosted on other sites are not loaded, because the App makes no external requests. Attach the image to the page with Confluence instead.

Security issues

Please report suspected vulnerabilities privately to security@lhbuyertech.us rather than through a public issue tracker. See the Security Policy.
